FLUX 계정 도움말

로그인이 취소됐어요

계정은 만들어진 것으로 처리되지 않습니다. 원할 때 Google 로그인 버튼을 다시 누르세요.

로그인 창이 열리지 않아요

팝업 차단을 해제하거나 일반 브라우저 창에서 다시 시도하세요. 승인 도메인 오류는 사용자 문제가 아니므로 운영 설정이 고쳐질 때까지 기다려 주세요.

비밀번호와 로그인 기기

FLUX는 Google 비밀번호를 받거나 저장하지 않습니다. 비밀번호, 2단계 인증과 로그인 기기는 Google 계정 보안에서 관리하세요.

계정을 탈퇴하고 싶어요

내 계정의 계정 탈퇴에서 확인 문구를 입력하면 Google 연결, 찜, 시청 기록, 알림, 나눔 설정, 기기 등록이 정리되고 로그아웃됩니다. 구매·환불·정산 기록은 법적 확인을 위해 탈퇴한 이용자 기록으로 보존됩니다.

광고가 보이나요?

운영자가 Google AdSense 게시자 ID와 광고 단위 ID를 연결하면 홈 상단, 홈 피드 중간, 작품 상세, 보관함 하단에 광고가 표시될 수 있습니다. 광고는 콘텐츠 카드, 다운로드, 구매 버튼과 별도 영역으로 분리됩니다. FLUX는 광고 클릭을 요청하지 않으며 광고 클릭에 포인트를 주지 않습니다.

설정 백업

내 계정에서 백업 파일 만들기를 누르면 이 기기의 언어와 하루 목표만 저장됩니다. 복원은 파일 검사와 미리보기 뒤 사용자가 확인할 때만 실행됩니다.

FLUX 로그인 기기를 해제하고 싶어요

내 계정 → 로그인 기기·보안 알림에서 다른 기기의 로그아웃을 누릅니다. 현재 기기는 내 계정의 로그아웃을 사용합니다. 다음 서버 요청부터 차단되며 Google 계정 전체의 로그아웃과는 다릅니다. 새 기기 로그인은 이 화면에 보안 알림으로 남습니다. 알림 발송 메일이나 문자 기능은 제공하지 않습니다.

백업 v1과 v2

새 백업은 v2 형식입니다. 기존 v1 파일도 검사할 수 있으며 원본 파일은 바꾸지 않습니다. 복원 취소나 화면 닫기는 설정을 바꾸지 않습니다. 알 수 없는 항목·인증정보가 포함된 파일은 거부합니다. 언어는 현재 한국어만 지원합니다.

브라우저별 설치 안내

  • Android Chrome: 메뉴 → 앱 설치 또는 홈 화면에 추가.
  • PC Chrome·Edge: 주소창 설치 아이콘 또는 메뉴의 앱 설치.
  • iPhone·iPad Safari: 공유 → 홈 화면에 추가. 메뉴 구성은 운영체제 판에 따라 다를 수 있습니다.
  • 메신저 내부 브라우저·Android WebView: 외부 Chrome 또는 Safari로 열어 로그인하고 설치하세요. Google 로그인은 내장 브라우저에서 제한될 수 있습니다.

인터넷 보안 연결(HTTPS)에서 열어야 설치 기능이 동작합니다. 설치 메뉴가 없으면 일반 웹으로 사용할 수 있습니다.

업데이트가 실패했어요

새 화면 파일을 전부 받지 못하면 기존 판을 유지합니다. 연결이 돌아온 뒤 다시 열고 새 버전 안내의 안전하게 새로고침을 누르세요. 브라우저의 전체 사이트 자료 삭제는 설정과 백업을 지울 수 있으므로 첫 해결책으로 사용하지 마세요. 인터넷이 끊긴 동안 계정·보관함의 최신 서버 자료는 확인할 수 없습니다.
